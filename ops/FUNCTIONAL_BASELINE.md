# AI Activity Studio 持久功能基线

更新时间：2026-09-28

## 防回退原则

- 本清单是本地完整功能最低基线，后续迭代只能增加功能，不得删除、隐藏、以其他页面替代或降低可用性。
- 修改导航、工作台、模型中心、高级配置、API、存储结构前，必须逐项检查本清单。
- 每次交付必须运行 `npm run typecheck`、`npm run build`、`npm test`，并使用真实浏览器回归核心路径。
- API Key 不得通过 API 响应、日志、错误、浏览器页面或测试输出回显；持久化文件只能保存加密值和不可逆指纹。

## P0 核心功能

### 五阶段串行工作台

- 固定包含：活动原稿、规则流程图、UE 设计、策划文档、交互 Demo。
- 五阶段全部使用统一左右双栏，桌面端左右各约半屏；窄屏允许上下堆叠。
- 左栏固定包含阶段说明、可编辑产物区、AI 聊天修改、上传、下载、保存、生成控制和任务轨迹。
- 右栏固定用于当前编辑内容的实时产物预览；无产物时显示明确空状态。
- 后端强制前序阶段完成后才可生成后续阶段；同阶段活动任务和已完成任务防重复，失败任务允许重试。
- 所有生成任务保留状态、尝试次数、错误和审计事件。
- 任务状态至少包含 `queued / running / paused / completed / failed`；排队中和运行中的任务均可暂停，运行中暂停必须中断模型请求并阻止迟到响应写入产物。
- 暂停任务可恢复到队列并重新尝试；暂停、恢复、尝试开始、产物保存、完成和失败均保留审计记录。

### 视觉阶段产物

- flow 与 ue 的正式产物必须是 SVG 或 PNG，右侧默认只展示图像，不得以 Markdown 文本代替正式预览。
- Demo provider 直接生成可视 SVG；模型返回 SVG、Mermaid 或普通文本时统一转换为安全 SVG，并保留可编辑 `sourceContent / sourceFormat`。
- SVG 必须移除或拒绝脚本、事件属性、`foreignObject` 与危险链接；用户上传 SVG 也走同一安全处理。
- flow/ue 仅接受 SVG/PNG 图片上传并支持原格式下载；PNG 按 Base64 持久化且下载字节不得变化。

### Demo 预览

- HTML Demo 在受限 iframe 中运行，允许脚本和表单，不允许逃逸沙箱。
- 使用 9:16 竖屏手机画布，桌面常见分辨率下尽量单屏完整显示。
- Demo 必须可交互，编辑区变更可实时映射到预览，保存后可下载。

### 模型中心

- 模型中心是独立一级页面，不得被高级配置或 Skill 页面替代。
- 支持添加、编辑、删除自定义 Provider。
- 支持 Base URL、API Key、模型 ID、启用/停用和连通测试。
- 编辑时 API Key 永不回显；留空表示保留原密钥。
- Base URL 只允许 HTTP/HTTPS；连通测试使用服务端保存的加密密钥。
- 返回给前端的模型配置只包含是否已配置密钥和指纹，不包含明文或密文。

### 高级配置与 Skill

- 高级配置保留按五阶段切换的 Skill 管理，不承载或替代模型中心。
- 每阶段至少保留一个内置默认 Skill。
- 支持 ZIP 上传、SKILL.md 校验、启停、下载和删除上传项；内置项不可删除。
- Skill ZIP 仅持久化，不解压、不加载、不执行、不注入模型请求。

### 活动项目管理

- 首页支持创建、编辑和删除活动，编辑不得破坏既有阶段产物与任务。
- 删除必须使用应用内自定义二次确认，并要求输入活动名称；取消确认不得发出删除请求或改变数据。
- 删除成功后必须同步清理关联生成任务和活动内嵌阶段产物，并中断关联运行请求，阻止迟到响应重新写入。

### 数据与安全

- 活动、阶段产物、模型配置、生成任务和 Skill 使用本地 JSON 原子持久化。
- 兼容旧活动类型、缺失 artifacts、缺失任务 stage/auditTrail 和缺失默认 Skill。
- API Key 使用 AES-256-GCM 加密，页面、响应和日志不得泄露密钥。

## 2026-09-29 生成异常与 502 修复

- Windows 原子替换数据文件遇到 EPERM / EACCES / EBUSY 时进行有上限的退避重试，成功前保留原数据；其他错误立即返回。
- 后台任务保存失败不得产生未处理 Promise 拒绝而使 API 退出；失败状态也无法持久化时保留读取及解除占用后的暂停能力。
- 工作台生成状态轮询改为逐次请求；连续断连只提示一次并逐渐降低重试频率，恢复后重新读取任务状态。
- 类型检查、构建与 26 项测试通过，包括短暂占用恢复、持续占用上限、后台存储故障时 API 存活及暂停验证。
- 体力清图活动 Demo 保持 paused，未重试公司网关；本地 API 与页面服务恢复，浏览器确认显示已暂停和继续入口。
