# 独立合成线

来源：[原独立合成线Word](../assets/MC活动策划标准模板.docx)。原技能里的有效经验在此保留；下面是该类型参考，不是新活动必须拥有的功能。

## 组织方式

原稿顺序为：开启 → 活动进行 → 奖励与弹窗 → 其他界面 → 关闭结算 → 引导 → 开关。活动进行中依次介绍主界面、棋子合成、核心操作与成长、倍率、待领奖区、图鉴、防卡死、代币来源。

新活动按实际内容选择。不要为保留旧编号而新增功能，也不要把新模块硬塞进9.2.1–9.2.4。

## 模块记录与写法

| 模块 | 应保留的描述重点 | 原稿中的案例与适用条件 |
| --- | --- | --- |
| 棋盘 | 格子状态、棋子能否移动、解锁或合成条件、结果位置 | 原稿有开放格、障碍气泡、半锁定格、未知盒子及奖励气泡；尺寸7×7只是案例 |
| 同类棋子 | 等级 → 获取方式 → 使用逻辑 → 生成规则 | 主线鱼与支线宝箱使用相同描述结构；只写当前活动真实合成线 |
| 生成器与成长 | 操作条件、消耗、产出、升级触发、升级后变化 | 钓鱼稿鱼竿升级更换外观及序列，里程碑只结算一次；等级阈值不能跨活动沿用 |
| 倍率或批量 | 各档消耗、结果变化、解锁条件、读取方式 | ×1/×2/×4是原稿档位；次数、数量和等级加成需分别说明，原稿存在待统一项 |
| 待领奖区 | 何时暂存、如何领取、同次和跨次排序、满盘表现 | 原稿超出开放空位的物品入队；不同批次后进先出，同批按品类与等级或ID排列 |
| 图鉴 | 纳入对象、首次获得条件、状态、单项与整线奖励、最终奖励、重置 | 原稿有未解锁、待领奖、已解锁；点击领取单项，整线及最终奖励自动触发；未领图鉴奖励到期不补发 |
| 防卡死 | 触发、可删与不可删对象、确认或取消后的状态 | 原稿满盘且无可合成棋子时触发；成功删除一个、取消或不再满足条件时退出 |
| 代币 | 每个已有来源的获得条件与数量口径 | 原稿有订单、体力消耗及礼包等记录；不能给其他活动默认加同样来源 |

待领奖品类、图鉴线、可删/不可删对象、资源清理对象始终属于当前活动内容。原稿的鱼饵、鱼竿、鱼获、支线宝箱、Bag及里程碑都不是固定槽位值。

## 原技能保留的公共流程记录

这些内容只在继续使用该独立合成线方案，或用户确认沿用时采用；遇到新要求以新要求为准。

- 开启：主界面判断资格；原稿等级7且完成第6波订单，服务器配置时间，每日03:00日切。互斥列表见原稿，不能复制给其他活动。
- 首次开启：同一期只初始化一次；封面点击开始进入活动。原稿“每期首次引导”与“账号首次强引导”有歧义，见待统一项。
- 断网入口：原稿显示无网络或已结束，点击尝试重连；未确认服务器时间不做真实结束结算。提示文案从当前选定稿取用。
- 产出恢复：原稿先记录扣除及结果，再播放表现；恢复时不重新随机、不重复扣除和发奖。保留此语义，不需要写事务或接口方案。
- 弹窗：原稿使用PopupsOrder，同一时间只展示一个；从二级界面返回后按队列展示。结算流程先结束弹窗，后补发弹窗。
- 引导：原稿记录账号首次强引导，中断后从已记录步骤继续；阶段内容按当前核心操作替换。没有引导需求时不新增。
- 软关：原稿允许本期继续完成和结算，之后不再开启下一期。
- 硬关：原稿活动内待玩家手动关闭后移除；活动外直接移除入口。这个“硬关”含义不能按通常技术理解擅自改成强制踢出。

## 结束与补发记录

原稿允许到期时仍在活动页的玩家继续操作，离开后结束；活动外移除入口。离线在结束后2天内登录可展示结束结果。此时长与停留规则仅为原稿方案。

| 原稿对象 | 原稿处理 |
| --- | --- |
| 已发放奖励 | 不重复处理 |
| 棋盘中可直接转化的奖励 | 结束弹窗后补发，直接资源入账户 |
| 三选一宝箱等棋盘道具 | 补领后进入主棋盘待领奖区 |
| 未领取图鉴奖励 | 不补发 |
| 普通活动棋子、代币、进度 | 结束后清空，不继承下期 |

新活动只复用已确认适用的行，不能自动加入三选一宝箱、金币折算或其他奖励处理。

## 对应配置

当前资料涉及时，可说明棋子链、生成器成长、产出序列、倍率、图鉴奖励、代币来源等配置。每张表说明每行对应的对象或档位，只选择已有字段。参考[数值逻辑配置](numerical-config.md)；原稿未确定的概率、权重、等级和解锁规则不补值。

使用原稿具体规则前核对[参考稿待统一项](reference-conflicts.md)。特别不要把倍率解锁、产出数量、资源不足时自动降档、图鉴进度口径写成已经统一的规则。
