# Merge 活动 Web Demo

建议先阅读 `Demo体验说明.md`，再打开 Demo。该说明使用非专业语言介绍玩法、操作、已实现范围与未实现项。

## 本地运行

直接打开 `index.html`，或执行：

```bash
npm start
```

然后访问 `http://localhost:4173`。

## GitHub Pages

将本目录文件上传至仓库根目录，在仓库 Settings → Pages 中选择从 `main` 分支的 `/(root)` 发布。
